# 鹰击长空 · Ethan Attack

一款单文件 HTML5 竖屏飞行射击闯关游戏（类早期《雷电》+ 星球大战风格）。

## 特点
- 纯前端单文件 `index.html`，无需任何依赖，双击即玩。
- 手机竖屏 + 电脑端自适应，触摸拖动 / 键盘双操作。
- 关卡制：歼灭定额敌机 → 迎战首领 Boss，难度逐关递增。
- 三种敌机（TIE / 王牌 / 轰炸机）、武器升级 / 护盾 / 炸弹道具、爆炸粒子与屏幕震动。
- WebAudio 简易音效，本地最高分记录。

## 操作
- 📱 手机：手指拖动战机移动，自动开火。
- 💻 电脑：方向键 / WASD 移动，自动开火。
- 💣 左下 `BOMB` 清屏，右上 `⏸` 暂停（键盘 `B` 炸弹 / `P` 暂停 / `M` 静音）。

## 本地运行
直接用浏览器打开 `index.html` 即可；或在目录下起一个静态服务器：

```bash
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 部署
代码已推送到 GitHub 仓库。如需公开访问，请在仓库
**Settings → Pages → Source** 选择 `main` 分支、`/ (root)`，保存后即可通过
`https://<用户名>.github.io/ethan-attack/` 访问。
